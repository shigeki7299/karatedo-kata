# 空手道 形指導アプリ

タブレット向けの形練習アプリです。左に見本（YouTube または保存した動画）、右に自分の映像（カメラまたは保存した動画）を並べて再生し、骨格を重ねて見比べます。

## できること

- 左右の映像を独立して再生する。画面をタップすると再生と一時停止が切り替わる。
- 「連動」は再生と一時停止だけを揃える。シークバーは左右別々。
- リボンを押すと、今のスライダー位置にしおり（▼）が付く。同じ動画を開き直すと、その位置に戻る。同じ位置でもう一度押すと外れる。▼を押すとその位置へ移動する。「◀◀」「▶▶」で前後のしおりへ移動する。
- ピンチで最大 4 倍まで拡大する。
- 骨格の表示を切り替える。
- 右画面で撮影し、動画フォルダへ保存する。ファイル名は日時と選択中の形名。撮影を終えると、そのファイルを読み込んで再生モードになる。
- 映像の選択は、左右ともダブルタップでシステムの文書ピッカー（`video/*`）を開く。
- 形の一覧は剛柔・糸東・松濤館・和道・劉衛の基本形・指定形・得意形。選んだ形は再起動後も残る。
- ＡＩ解析は撮影・再生の隣にある。右の映像をスライダーの位置から再生し、再生が止まるまでの姿勢で技術点と競技点に分ける。解析中はボタンが緑になる。

メニューは次のとおりです。

| 項目 | 内容 |
| --- | --- |
| お手本設定 | 各形の見本URLを設定する。形を選ぶと、保存したファイルがあればそれを左画面に読み込み、なければURLを使う |
| グリッド表示 | 映像の上の9マスをON/OFFする |
| ２画面差分採点 | 左右を今の位置から同時再生し、腰の高さ・バランス・切れ・体幹を比べる（各 25 点、合計 100 点） |
| 形競技採点基準 | 得点配分と減点の基準を表示する |
| 形競技実施要領 | 参加人数ごとの演武数と進行を表示する |
| 基本動作と基本技術 | 日本武道館の少年少女武道指導書Ⅲ章を表示する |
| HELP | この説明を表示する |

２画面差分採点には左右両方の映像が必要です。ＡＩ解析に必要なのは右の映像だけです。左の見本も、保存したお手本 JSON も使いません。

## 使っている AI

クラウドの生成 AI は使っていません。チャットや外部 API への送信もありません。

姿勢の検出だけが機械学習です。

- ライブラリ: [ML Kit Pose Detection](https://developers.google.com/ml-kit/vision/pose-detection) `com.google.mlkit:pose-detection` 18.0.0-beta5
- モデル: 標準のベースモデル（33 関節）。正確モデル（`pose-detection-accurate`）は使っていない
- 推論: 端末内。再生中は `STREAM_MODE`、お手本の保存時は `SINGLE_IMAGE_MODE`
- モデル本体は Google Play 開発者サービス経由で端末に入る。フレームをクラウドへ送って推論する方式ではない

点数とコメントは、その関節座標をアプリ内のルールで計算しています（`KataAnalysis.kt`、`KataScore.kt`）。学習済みの採点モデルではありません。MediaPipe、ST-GCN、LiteRT は入っていません。

ＡＩ解析の内訳は次のとおりです。各軸は 0〜100 で、高いほど良いです。ふらつきは揺れが少ないほど高くなります。

- 技術点（70%）: 立ち方、技、移行動作、呼吸、極め、リズム、正確さ、形の難度、ふらつき、元の位置
- 競技点（30%）: 力強さ、スピード、バランス
- 合計は技術点（0〜70）と競技点（0〜30）の和

呼吸は音声を聞いていません。動きが止まった間から推定します。形の難度は演武の上手さではなく、選択中の形の名前から決めています。コメントは点数が低い軸に対応する定型文です。

## 操作の要点

- ＡＩ解析は右の映像をスライダーの位置から再生し、一時停止するか最後まで再生するまでの間で判定します。最後まで見終わっているときは最初から再生します。
- 右の映像がない状態でＡＩ解析を選ぶと、「右の映像を読み込んでから解析してください。」と出ます。
- 解析中、映像の下の「ダブルタップで映像を変更」は「AI解析中」になります。終わると元に戻ります。
- 左と右に同じファイルは選べません。
- YouTube の保存ファイル名は `空手形_youtube_{動画ID}_{時刻}.mp4` のままです。表示名を変えても、既存の保存ファイルを判別するための接頭辞は変えていません。

## ビルド

- Android Gradle Plugin 9.2.1、Gradle 9.4.1、Kotlin 2.2.10
- `compileSdk` 37.2、`targetSdk` 36、`minSdk` 26、Java 17
- Jetpack Compose、CameraX、Media3、AndroidX WebKit

権限はインターネット（YouTube）、カメラ、録音だけです。

横向きのタブレットを想定しています。
